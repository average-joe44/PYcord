# PYcord
## What is it
PYcord is a Discord RAT that uses C2 concept and post-exploitation techniques.
## Features
PYcord featuring multiple cool commands you can use to control your targets, including:
```
GENERAL COMMANDS:
.ls to list directory
.cd to change directory
.who to show current machine, user, and pid
.hello to make the bot respond
.marco to show latency
.rmv to remove file
.exe to run command/program
.size to show file size
.addstartup to do persistence technique
.recordmic to record mic
.stoprecord to stop mic recording early
.hide to hide file icon from explorer
.screenshare to screen share from target to your browser
.stopsharing to stop screen sharing
.enablekey to enable keyboard input
.disablekey to disable keyboard input
.enablemouse to enable mouse input
.disablemouse to disable mouse input
.streamcam to streaming webcam from target to your browser
.stopcam to stop webcam stream
```
```
FILE TRANSFER:
.download to turn a file into downloadable link
.upload to plant a file from a link
```
```
LOGGING:
KEYLOGGER:
.keylog_start to start keylogger
.keylog_read to dumps keylogger
.keylog_stop to stop keylogger

CLIPLOGGER:
.cliplog_start to start cliplogger
.cliplog_read to dumps cliplogger
.cliplog_stop to stop cliplogger
```
## NOTE
In order to run screenshare/streamcam function you'd have to install a tunneling service in your computer!!!  
And before you run the screenshare/streamcam function, you have to run the serverScreenHolder first and bind it with your tunneling service port.
